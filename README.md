# Задача №6: повороты в пространстве через кватернионы
## Цель: 
Реализовать класс Quaternion и использовать его для поворота 3D-векторов

## Зачем это нужно:
- Избегание gimbal lock (в отличие от углов Эйлера)
- Эффективная композиция поворотов через умножение кватернионов
- Стандарт в робототехнике, графике, симуляциях и задачах ориентации

## Что требуется:
- Реализовать класс с арифметикой кватернионов (сложение, умножение, сопряжение, норма)
- Реализовать поворот вектора по формуле v′ = q · (0, vx, vy, vz) · q⁻¹
- Написать тесты на корректность поворотов и композиции

---
Примечание: внешние библиотеки для самой математики кватернионов использовать нельзя;
pytest и math — можно
